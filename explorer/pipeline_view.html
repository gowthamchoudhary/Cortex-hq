Cortex HydraDB Pipeline

A runnable map of the ingestion, resolution, temporal, reasoning, and inspection flow.

Pipeline Diagram

flowchart LR A[EnterpriseRAG-Bench Raw Sources
Fireflies / Gmail / Slack / Jira / GitHub] --> B[ingestion/normalize.py
RawDocument] B --> C[extraction/extract.py
Entities / Relations / Facts] C --> D[graph/ingest_to_hydradb.py
HydraDB graph_payload] D --> E[(HydraDB
Entity / FactState / Relations)] E --> F[resolution/dedup.py
Near-duplicate docs] E --> G[resolution/entity_resolution.py
Merge candidate entities] E --> H[temporal/truth_discovery.py
Learn authority_weight] H --> I[temporal/conflict_cascade.py
Current / Superseded / Disputed] G --> I I --> E E --> J[reasoning/answer_question.py
Graph-grounded answers] J --> K[reasoning/calibrate_threshold.py
Calibrated abstention] K --> J E --> L[explorer/knowledge_explorer.py
Inspect entity facts/history] E --> M[eval/baseline.py
Partial-corpus baseline]

Typical Run Order

python ingestion/normalize.py Datasets/gmail --source gmail
python extraction/extract.py --sample-file path\to\normalized_sample.json --source gmail --limit 10
python graph\ingest_to_hydradb.py path\to\extraction_output.json --limit 30

python resolution\entity_resolution.py
python temporal\truth_discovery.py --iterations 8
python temporal\conflict_cascade.py --use-learned-authority

python reasoning\answer_question.py "Why is Atlas delayed?" --verbose
python -m streamlit run explorer\knowledge_explorer.py

Ablation Toggles

python resolution\entity_resolution.py --disabled
python temporal\conflict_cascade.py --disabled
python reasoning\answer_question.py "Why is Atlas delayed?" --disable-abstention
python reasoning\answer_question.py "Why is Atlas delayed?" --disable-graph-reasoning --disable-abstention
