Thanks — quick technical notes:

- Latency: 95th pct for chat (typical payloads, 25–75 tokens) is 85–110ms on our dedicted-2 profile; embeddings 95th is ~120ms for batch size 32. Caveats: prefix-heavy KV cache warmups (>2k tokens) push the 95th upward by ~40ms for the first few calls.

- Export streaming: Continuous streaming export is feasible but requires enabling a per-account mirror stream and a small infra change that adds ~2ms per write and additional S3 egress costs. Ops side impact is low but there is an infra rollout window (we'd need a canary and a 48–72 hour bake).

- Fallback: Automatic routing to a backup region is supported by our smart routing layer but only if the model variants are available in both regions. For Apex we'd need to pin a compatible quantized variant in eu-west (there's a 1–2 week onboarding + validation).

Proposed milestones:
- 7/16: Provide slide blurb + short tech caveats
- 7/18–7/20: Canary rollout for streaming export for a small subset (if Apex opts in)
- 7/29: Finish region-side model validation for fallback
