Goal (technical milestone): Validate model selection and runtime configuration to meet production latency and cost SLOs while preserving classification accuracy for triage flows.

Success criteria (benchmarks):
- Accuracy: intent classification F1 >= 0.92 on CareScale redacted test set (primary)
- Latency: p95 response time <= 150 ms for typical prompts (~256 tokens) on <200ms cold-start targets (measured at Redwood hosted endpoints)
- Throughput: baseline 200 req/s sustained for 1 minute bursts
- Cost target: target inference cost <= $0.0009 per token for the 256-token baseline (aim to optimize via batching/quantization)
- Regression gating: no >2% drop vs baseline on prioritized prompt subset

Model shortlist (initial):
- Mistral-Instruct-7B (int8 quantized) — good cost/latency tradeoff
- Llama-2-13B-chat (int8) — strong instruction-following baseline
- OpenAssistant-30B (quantized) — higher quality candidate for hard edge cases (evaluate at lower QPS)
