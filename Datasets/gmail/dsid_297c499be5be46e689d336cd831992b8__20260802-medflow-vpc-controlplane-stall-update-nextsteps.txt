- Root cause: a race between certificate rotation and agent connection backoff logic that, under our current backoff settings, caused a concentrated connection retry burst and exhausted the proxy worker thread pool in two AZs.
- Why it reached customer impact: the proxy worker exhaustion caused health-check responses to timeout, which the cluster manager interpreted as unresponsive nodes and triggered additional reconciling operations.

Short-term fix (applied 08:05):
- Increased agent jitter/backoff window and scaled proxy worker pool by 40% for the MedFlow instance group.
- Rolled back the in-progress cert rotation where safe.

Longer-term actions (tracked in infra backlog):
- Change cert rotation orchestration to stagger by AZ with per-agent cooldown windows.
- Harden proxy worker pool with a soft limit and circuit breaker so retries don’t fully exhaust resources.
