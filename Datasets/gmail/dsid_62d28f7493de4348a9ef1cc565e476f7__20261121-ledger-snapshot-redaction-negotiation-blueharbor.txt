Paul — appreciate the clear list. We can provide the artifacts you describe; a few clarifying points so we package exactly what your auditors expect:

1) Event coverage: our admin action ledger includes authentication events, privilege elevation, role assignments, API key creation/deactivation, operator session starts/stops, config changes to model routing and rollout rules, and manual overrides. It does not include request payloads (user content) by default.

2) Retention window: standard offering is 18 months rolling for admin-level audit events. We can provide longer retention under an enterprise contract; worth flagging if BlueHarbor needs 36 months.

3) Export shapes & delta cadence: we recommend daily delta files in newline-delimited JSON (JSONL) plus a compressed weekly snapshot for the requested window. Each file includes an event index, ISO timestamps (UTC), actor_id (internal user id), actor_role, event_type, resource_path, and metadata.

4) PII redaction: our default flow replaces email/username fields with deterministic anonymized ids (sha256(email) truncated) and emits a redaction_map CSV for auditor reconciliation. If you require pseudonymization (reversible under HSM), that needs an approved process and contract amendment.

5) Integrity & manifest: we produce a signed manifest (JSONL manifest_template attached) that lists filename, byte_size, sha256, and an HMAC-SHA256 computed with a transient key. We can sign with customer-shared key or with our KMS-based attestation.

6) Transfer options: SFTP push to a customer endpoint, or time-limited cloud storage links (GCS/AWS S3 pre-signed). For high-sensitivity runs we support direct SFTP + GPG-encrypted archives.
