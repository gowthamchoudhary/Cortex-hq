2) Model routing & fallback (technical proposal)
- Primary inference config: Llama-3 13B q4f32 (quantized) deployed in our dedicated staging pool. Good multilingual baseline for EN/ES/FR.
- Fallback model: Mistral 7B q4f16 — used when confidence < threshold or when observed token-level perplexity spikes. Mistral tends to be cheaper and lower-latency for short-turn responses.
- Portuguese (pt) handling: we'll add a small PT-tuned 7B variant into the A/B candidate pool. Routing rules:
   * If primary intent confidence < 0.70 OR entity extraction F1 drops below 0.65, route to fallback automatically for that request.
   * Persist routing at session-level for an agent session to avoid flip-flopping.
   * Log both outputs for post-hoc comparison.
- We'll implement a conservative 5% sample shadowing to quantify mismatch before routing is fully live.

3) Cost estimate (very rough for trial window)
- Baseline (Llama-3 13B, dedicated staging, 2k prompts): ~$1.2k–1.8k total tokens + infra (estimate).
- With fallback routing active: add ~20% to cost (Mistral runs on 5–10% of requests initially).
- We'll provide a daily cost dashboard so procurement sees burn in near real-time.

4) Evaluation harness & metrics
- We'll ship a lightweight eval harness (script + scoring CSV) that runs your holdout test and outputs: intent accuracy, entity F1, latency p50/p95, and a small hallucination sample with human labels.
- Thresholds (as proposed): intent >=85%, entity F1 >=78%, p95 <250ms on staging. We'll flag regressions and run a quick follow-up if metrics miss targets.
