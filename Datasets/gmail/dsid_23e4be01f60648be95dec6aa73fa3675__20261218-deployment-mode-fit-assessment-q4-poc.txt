Thanks for the flag, Olga. Quick answers / suggestions: 

- Network fencing (Dedicated): we run tenant-dedicated GPU pools with virtual network isolation and per-tenant NAT. For auditors we can produce network diagrams, flow logs, and a tenant isolation design doc describing how egress is restricted and how packets are NATed through tenant-dedicated endpoints. We cannot (today) provide a fully customer-controlled control plane in the hosted Dedicated service; that’s only available in Private deployments.
- BYOK / KMS: Dedicated supports customer-managed keys (BYOK) for model payload encryption at rest. We can also forward audit logs (CloudTrail-equivalent) to their SIEM via a secure log-forwarding connector.
- Cost / timeline: for a 2-week POC at ~100 reqs/s peak — estimate: Dedicated POC = ~USD 32K (reserved short-term capacity + minimal engineering effort). Private VPC POC (customer VPC + private control plane) = ~USD 68K (higher infra and setup + infra eng time). Exact numbers need infra sizing validation from Karthik.
