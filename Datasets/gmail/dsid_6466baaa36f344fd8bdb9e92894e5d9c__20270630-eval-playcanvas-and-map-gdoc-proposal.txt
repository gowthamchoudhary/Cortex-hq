Adding a very short slide deck draft and a compact week-by-week canvas below — happy to expand once we see Vertex's stakeholder list.

Week-by-week (6-week pilot) — proposed owners and acceptance gates:
- Week 0 (prep): infra access, test dataset subset, security checklist signed — owner: Vertex infra
- Week 1 (integration): API integration, basic inference smoke tests — owner: Vertex devs; acceptance: stable inference < 20 errors/day
- Week 2 (validation): run 12-sample prompt suite, collect outputs, measure quality metrics — owner: product lead; acceptance: >= 85% pass by rubric
- Week 3 (load): small concurrency load test, monitor latency/cost — owner: Redwood infra; acceptance: P95 < 200ms, cost within expected range
- Week 4 (decision gate): review outputs + runbook readiness — joint review; outcome: scale or halt
- Weeks 5–6 (scale & harden): expand to broader dataset, address security items, finalize runbook

Attachments I left: acceptance-slate.pptx (one-slide matrix), and a condensed checklist PDF. Also flagged a slide for procurement pricing scenarios.
