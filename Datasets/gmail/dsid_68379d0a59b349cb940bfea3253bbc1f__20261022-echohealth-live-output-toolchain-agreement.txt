Elena / Jasmine — adding a short technical checklist here so the EchoHealth SREs know what's required before tests:

- Schema validation: validate responses against echohealth-onboard-schema-v1.json. Failures should return a 400 with details.
- Streaming session TTL: clients must send initial auth token; sessions expire after 60m idle.
- KV caching: recommend prefix caching for repeated patient metadata to keep p95 under target.
- Toolcall auth: Redwood function calls expect an HMAC header + TLS client cert; we can accept OAuth bearer for dev sandbox.
- Retry policy: idempotent toolcalls should be retried 2x with exponential backoff (200ms -> 600ms).
- Observability: include a json.trace_id field in the structured output for cross-system tracing.
