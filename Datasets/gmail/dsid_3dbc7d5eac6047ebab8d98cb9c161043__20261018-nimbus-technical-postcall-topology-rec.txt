Technical requirements you called out

Suggested deployment topology (initial recommendation)
- Dedicated pool for core assistant (2x H100s per shard) with autoscale policy that scales by request queue depth + burst capacity using a separate warm pool of A100 nodes for reserve capacity.
- Multi-AZ in us-west-2 with cross-region fallback to us-east-1 for DR (non-PII local only).
- Prefix caching for session hot paths (cache TTL 90s) + persistent KV cache for user sessions to cut token regen cost.
- Quantization path: run experiments on 8-bit GGML-style quantization for the 70B variant and 4-bit for the 40B fallback; routing policy to prefer smaller model during non-peak.
