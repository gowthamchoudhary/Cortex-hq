Thanks for the detail and the questionnaire. Quick summary from product/compliance side so legal knows the bounds:

1) Residency & deployment modes- Hosted (our standard public API) cannot guarantee financial-only onshore residency for all telemetry and transient KV cache; we can offer strong controls but not full residency isolation.
- Private (VPC/on-prem) supports onshore residency and is the recommended path if Midwest requires all processing and logs to stay on US-based infrastructure.
- Dedicated can be an intermediate option if you need predictable throughput and can tolerate limited shared-control plane metadata in the US.

2) KMS / encryption- We support Customer-Managed KMS keys for Private deployments (bring-your-own KMS via integration with supported cloud KMS/HSM). For Hosted API we offer Redwood‑managed KMS; we can provide key usage attestations but not customer key import into our multi-tenant hosted environment.

- Evidence we can reasonably provide in 3–7 business days: network diagram, dataflow mapping, SOC 2 report snapshot, endpoint security attestations, and a list of model/serving variants used for the pilot.
