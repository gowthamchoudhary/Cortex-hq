   - KMS integration: test key wrapping/unwrapping via Redwood KMS passthrough

   - Hosted API (short smoke), Dedicated (reserved GPU pool), Private (VPC peering test)

   - Verify model artifact formats (fp16 / int8 quantized) and model config (kv cache semantics)
   - Run small/medium/long sequence latency sweeps (1-4k tokens)

   - Need SOC2 evidence for NebulaWorks and any attestations around HSM/KMS usage
