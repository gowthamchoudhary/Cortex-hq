Marissa / Team — reviewed the proposed Exhibit B redline. High-level guidance:

1) PO acknowledgement: we should accept a statement that an automated system ACK confirms receipt of the PO (useful for tracking), but we should explicitly carve out that ACK via API is not equivalent to acceptance of contractual change requests or waiver of Redwood's rights to dispute invoice line items. Suggested clause: "Receipt acknowledgement via electronic API or vendor portal shall confirm receipt for logistics and scheduling purposes only and shall not constitute conclusive acceptance of disputed charges or modification of payment terms without separate written agreement."

2) GL / invoice codes: add an obligation that MedicaCorps will expose Coupa mapping metadata to Redwood via the enrollment response so Redwood can attach an "invoicing_hint" to outgoing invoices. The contract should state this mapping is for convenience and final GL routing is controlled by MedicaCorps finance.

3) Timing: 48-hour ACK window is reasonable. Add an operational fallback: if Redwood does not send an ACK within 48 hours due to an outage, MedicaCorps will attempt to reach Redwood; automated ACK-by-system may be enabled only after the parties provision the API key and confirm webhook reliability in a joint smoke-test.
