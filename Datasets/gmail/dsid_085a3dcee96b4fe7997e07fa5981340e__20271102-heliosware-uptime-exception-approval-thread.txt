Ava / team —

High level: feasible but non-trivial. Notes below: 
1) The p95 <120ms for mixed workloads is achievable on a Dedicated pool if we:
   - pin them to an isolated GPU pool with consistent instance type (A100-80GB or equivalent),
   - enable aggressive prefix KV caching for generative requests, and
   - ensure we have a hot-standby pool in a second region for cross-region failover (their contract requires <15 min RTO on region outage).
2) Operational impact: we'll need to reserve ~20-25% extra capacity as warm standby for typical traffic spikes and for failover; for peak patterns the scheduler must prefer preemptible avoidance for these nodes.
3) Engineering changes: minor runtime tuning + a short routing policy update (2 engineers, 2 weeks).
4) Risk: quantization/low-precision kernels may increase variance — we recommend locking to the validated model variant and prohibiting automatic quantization changes for this account without an eval gate.

Estimated monthly incremental cost: rough ballpark $45k–$65k above their baseline Dedicated commit (driver: reserved warm standby + cross-region replication + SRE on-call rotation uplift). This is a conservative estimate; finance should firm up numbers.

My vote: APPROVE pending written SLAs and a defined runbook for failover. I can own the engineering verbiage and provide a short tech addendum in 3 business days.
