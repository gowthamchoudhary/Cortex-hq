Folks — did a quick pass over the Terraform/Helm/Ansible repos (thanks for access, Luis). High-level findings and concrete redlines attached (tf-module-review-notes-20270316.patch). Summary: 

- Terraform:
  * Avoid remote state backends that require S3/GCS with public endpoints. Use on-prem state backend (Consul/HashiVault storage) or SFTP store behind the management network.
  * Replace aws_ami lookup with a pinned AMI ID per-region in a secure mapping file; automated lookups break airgap.
  * Split networking module to separate management-plane subnets vs. inference-plane subnets — explicit security group egress denies to 0.0.0.0/0 by default.

- Helm:
  * Add a values.yaml override for image repository mirror + tag pinning. Provide example helm-values-sanitized.yaml.
  * Chart pre-install hook currently pulls a remote init container image; change to a local init image and document mirror process.

- Ansible:
  * Many roles call get_url/tasks to fetch releases from GitHub. Replace with a local artifact server step and update playbook to checksum-verify artifacts before install.

- CI/CD:
  * Block merges to main until a terraform plan is produced against a staging VPC (dry-run environment) and a signed promotion artifact is produced by an internal signing job.
  * Recommend a gated artifact repository (Nexus/Artifactory) with controlled replication to the airgap mirror.

Low/medium/high risk tags are included in the patch. I'll bring the patch and sanitized Helm values to the walkthrough.

Thanks for the notes, Irene — agreed. During today's walkthrough we validated most of the items and sketched an implementation cadence. Concrete CI gating proposal (summary):

- Stage 1 (PR checks): terraform fmt + tflint + check for provider download blocks. Helm lint + ensure image.repository is set to mirror pattern.
- Stage 2 (Plan job): run 'terraform plan' in isolated staging account (ephemeral VPC) and upload plan artifact to internal storage.
- Stage 3 (Sign & Promote): a signing job (manual approve) creates a promotion bundle (signed JSON) and uploads to Nexus. Airgap deploy jobs only consume signed bundles.
- Rollback: Keep last-known-good signed bundle accessible and a policy that requires manual approval for any unsigned promotion.

Operational notes:
- We'll need a small bootstrap bastion with a one-way egress window (strictly controlled) to seed the artifact mirror; after seeding we close the window and rely on physical media or vendor sync SOP for updates.
- Add automated plan-drift detection that runs weekly and posts a summarized delta to the internal collector (JIRA-PRIVDEPLOY-412).

I added low-level tickets for the three terraform modules that need immediate splits (networking, bootstrap, and secrets). Karthik — can you confirm procurement timeline so we can schedule the artifact signing appliance (HSM) procurement?
