Thanks everyone — attaching a terse SLO acceptance checklist and the measurement definitions we'll use for the pilot. Please review and reply with any changes. (Attachment: slo-checklist.xlsx)

High-level acceptance criteria we'll test during the pilot (summary):
- Measurement windows: 95th pct over 5-minute sliding windows sampled every 30s.
- Streaming-first-token measured separately; SDK timestamp of receipt used as T0.
- Throughput: peak sustained 600 rps over 2-minute windows without degradation of 95th pct target.
- Concurrency: system should maintain SLOs at 80% of target concurrency; we'll define a safety plan if we need to increase pool sizes.
- Regression gates: any regression >10% on 95th pct vs baseline requires rollback or mitigation steps before production rollout.

Requests for Neptune SRE before pilot start:
