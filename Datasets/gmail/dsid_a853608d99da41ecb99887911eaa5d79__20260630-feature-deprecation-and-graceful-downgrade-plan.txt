Hi all — technical notes to help prioritize:

- The main compatibility risk is the legacy KV-cache flush behavior; if you use long-lived sessions, expect an integration change.
- Quick mitigation: enable prefix-level caching and increase session TTLs during the migration window.
- For most customers, switching to the streaming API reduces token churn and can lower unit costs by ~8–12% after reprofiling.

Proposed timeline:
- July 1: enable compatibility runtime (if confirmed by Tue EOD)
- July 15–Aug 15: migration and canary rollout
- Aug 16–Sept 15: monitoring and rollback window
