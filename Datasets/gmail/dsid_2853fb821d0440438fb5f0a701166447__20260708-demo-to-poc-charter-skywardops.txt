Thanks for the questions — answers below and a slightly expanded timeline so we’re all aligned.

Retention: 30 days is fine. We will not persist PII — ingestion flow will hash/redact at the edge before storage. Monica will reach out with the exact hash pattern and confirmation of ephemeral logging.

Latency: Our 95th-percentile targets we quoted exclude customer network egress — to be conservative we’ll measure both (1) Redwood runtime p95 excluding network and (2) end-to-end p95 including network hops to us-west-2. We’ll include a short network synthetic to estimate added tail latency.

Security evidence (minimal for POC):
- Access control list for POC resources (IAM roles)
- Data handling note (redaction/hashing)
- Short SOC2 snapshot + controls summary (Monica to attach)

Revised POC timeline (2.5 weeks, condensed):
- Prep (3 business days): access provisioning, sample dataset sync, baseline smoke run
- Integration (5 business days): API integration, example prompts, initial perf runs
- Scale & analysis (4 business days): 1M-token scale test, batching experiments, cost model
- Wrap & handoff (2 business days): findings doc, config recommendations, next-steps meeting
