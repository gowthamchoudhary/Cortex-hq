Team — attaching raw artifacts (concurrency-run-20260612.jsonl, server-metrics-20260612.tar.gz). Below are observed numbers from today's runs (redwood-13B-fp16 unless noted). All runs executed in our us-west cluster.

Summary (steady-state @ 110 qps):
- P50 token latency: 48ms
- P95 token latency: 210ms
- Mean TTFT (first token server-side): 85ms
- Sustained throughput: ~14.5k tokens/sec (aggregate across serving pool)
- Queue depth: typically 0–2 requests, spikes to 8 when concurrent short bursts overlap
- GPU util: 62–78% during steady-state; CPU (host) 35%
- 5xx: 0 for steady-state runs

Burst behavior (500 qps, 2-min shots):
- Immediate increase in queue depth up to 32 requests within 30s; average per-request queuing wait 120–260ms
- P95 token latency during bursts: 520–780ms (exceeds Claire's target)
- TTFT tail: spikes up to 340ms under peak queueing; cold-shard spinups accounted for ~60ms extra TTFT on some runs
- Observed throughput cap: about 28–30k tokens/sec aggregated before token-drop started for largest seq lengths
- Error mode: transient 429s when request bursts saturate rate limiter for a single serving shard; overall request success 97–99% depending on sequence length

Engineering notes / suggestions:
- Short-term: introduce a soft global request-rate limit per-customer (recommended 200 qps) plus token-based guardrails to avoid long sequences pushing tokens/sec beyond provisioned capacity.
- Burst mitigation: enable short-lived admission control with early 503-backpressure signals to client for overload scenarios; this produces better tail behavior than synchronous queueing.
- Autoscale: recommend reducing scale-up cooldown to 30s and enabling predictive pre-warm for scheduled campaign windows (based on customer's past traffic).
- Caching: prefix caching for repeated prompt starters would drop per-request token generation by ~8–12% in our traces.

Action items for MAP:
- Add a contingency line: If P95 > 500ms in bursts, provision a 1-week pilot with throughput-optimized variant (redwood-small-optimized) and a discounted pilot rate.
- Update MAP milestone: add a pilot-start gate (if needed) by 2026-06-20.
