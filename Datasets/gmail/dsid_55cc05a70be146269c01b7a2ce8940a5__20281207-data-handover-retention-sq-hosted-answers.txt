Hi Rajesh / team,

Thanks for the questionnaire — attached are our finishes and artifacts (data flow map + retention matrix + deletion playbook). Below are direct answers to each of your numbered asks to make procurement review easier. If you'd prefer a one-page attestation, we can provide that as well.

1) Physical storage locations (where request payloads & responses live) - Hosted API default: data is processed and stored in the cloud region you select at account creation. For Skyline's account we can pin to US (us-west-2) or EU (eu-west-1) depending on your preference. By default (if unspecified), Redwood routes to the nearest regional pool which is currently US. Persistent artifacts are stored on the configured cloud region's object storage and block stores; ephemeral caches may be serviced from local SSDs in different zones for performance but are short-lived (see retention windows below).

2) Default retention windows (hosted API) - Transient/LRU cache (in-memory / SSD): max 14 days; primarily for KV cache and prefix caching to optimize latency.
- Request/Response logs (full content for debugging & support): default retention 30 days. These are encrypted at rest and accessible only to an authorized small on-call support group under documented access controls and audit logs.
- Audit logs & metadata (access events, routing, billing): default retention 365 days.
- Backups & snapshots (system-level backups that may include metadata): 90–180 days depending on snapshot cadence; backups are immutable for a limited window to support disaster recovery.
- Aggregated telemetry and anonymized metrics: retained up to 3 years for capacity planning and model performance monitoring (always aggregated and pseudonymized).

Notes: we offer Enterprise configuration to shorten retention windows and disable request/response log retention entirely for customers with strict requirements; these are contractual controls.

3) Region restriction options - Yes — Skyline can elect regional pinning for all data in the hosted API: US-only (us-west-2), EU-only (eu-west-1), or APAC (ap-southeast-1) where available. Region pinning is an account-level feature we enable during onboarding and requires a migration window (~2–4 weeks) if you are already active on the default routing. Multi-region replication is optional; if disabled, failover to other regions is prevented and we publish an SLA addendum.

4) Deletion process & evidence - Deletion request types:
  a) Object-level deletion (single request/record): customers can call the Console deletion endpoint or submit a support request. We process and confirm within 3 business days. Evidence: deletion ticket + job id + log entry.
  b) Bulk erasure (tenant-wide): we offer a formal erasure process for account-wide removal; timeline depends on artifacts included (caches, logs, snapshots). Typical completion and evidence (for hosted): 7 business days for active datasets and up to 30 calendar days if deep backups/snapshots require rebuild/rewrite. Evidence package includes deletion job ids, checksum verification where applicable, and a short attestation signed by our Compliance team.

Backups: immutable backups may contain copies of data for disaster recovery. For hosted customers, we can either:
  - remove records from the primary dataset and mark backups for overwrite at retention expiry (default), or
  - if contractually agreed, execute targeted backup scrubbing where feasible and provide forensic evidence (this can increase deletion timeline).

5) Encryption & key management - Hosted (standard): data at rest and in transit is encrypted using provider-managed KMS keys (AES-256, TLS1.3). Redwood manages the lifecycle of these keys for hosted accounts. Access to keys is limited via RBAC, and key access is audited.
- Hosted (enterprise option): Skyline can opt for customer-managed keys (CMK) via AWS KMS or equivalent where Redwood holds no ability to export plaintext. Key rotation is supported on customer schedule; access audits are provided monthly (or on-demand for audits).

Operational controls & auditability - We maintain a documented access control matrix and provide on-demand export of access logs for compliance reviews.
- Deletion/evidence artifacts are delivered to the customer via secure Drive link and recorded in the support ticketing system (we can also deliver via DocuSign-signed attestation on request).
