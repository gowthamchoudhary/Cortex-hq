Thanks Rishi — adding details for Emily below. I reviewed ACME's redlines and annotated the DPA. High-level notes:

- Subprocessors: attached is our current disclosure (Redwood_subprocessor_disclosure_2026-07.pdf). Primary subprocessors include: AWS (EC2, S3 - storage for checkpoints), GCP (optional regions for embeddings processing), HashiCorp Vault (secrets management), Datadog (telemetry), and a managed inference partner for specific accelerators. For Dedicated deployments we can enumerate the same list but note that customer data processed inside Dedicated GPU pools is isolated; for Private/VPC deployments there is no data egress to Redwood-managed shared services except the control plane (metadata routing) unless the customer requests Redwood-managed auxiliary services.

- Cross-border transfers: for Hosted & Dedicated we apply SCCs for EU data subjects when required and maintain a Data Processing Addendum that references SCCs; for Private/VPC we offer configuration options to keep all data inside customer VPC and to avoid Redwood-hosted storage in EU->US flows. If ACME needs contractual assurance, we can add a clause: "Redwood will apply European Commission SCCs for any transfer of personal data outside the EEA and provide executed copies on request."

- Retention & logs: we can commit to 90-day requestable audit-logs for Dedicated and Hosted. For Private/VPC, retention depends on customer-managed logging — we can provide guidance and an optional managed-logging add-on for 90 days. SOC2 report can be shared under NDA.
