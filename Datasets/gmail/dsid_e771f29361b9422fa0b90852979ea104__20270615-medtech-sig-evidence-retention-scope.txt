Emily, Soojin —

Operational note from infra: our current default retention is as follows (production hosted API):

- Raw request payloads containing full input: 30 days (default, redacted for customer requests).
- Access logs (authentication events, request metadata): 90 days raw; we store aggregated access summaries for 365 days for usage analytics.
- Telemetry/metrics: 24 months aggregated, per-project.

For MedTech-style regulated audits, we typically offer a customer-specific exception that extends access logs retention to 24 months (raw metadata only, no customer payloads) subject to:

- Approved exception form signed by customer's security and procurement + Redwood legal sign-off.
- Logs stored in the requested region (us) and encrypted using Redwood-managed CMKs unless a customer-managed CMK is provisioned (additional onboarding time required).
- Monthly redacted snapshots delivered to an S3 bucket or via secure transfer for your audit team.

Emily —

Confirming technical details you requested:

- Raw request payloads: we will not include these in any extended retention. They are redacted at ingestion for hosted API customers who request deletion/TTLs.

- Deletion workflow (high level):
  1) TTL engine marks records for deletion at expiry;
  2) Background job performs cryptographic destruction: keys that exclusively encrypt the object are rotated/zeroed and object metadata flagged deleted;
  3) For backup snapshots, we maintain a 30-day tombstone window to support accidental restore requests, after which backups containing the object are purged following the same key removal process;

- Key rotation: rotating CMKs does not affect ability to read historical logs if the rotation policy uses key versioning — we maintain key-encryption-key (KEK) metadata so we can decrypt historical blobs for audit. If a customer requests use of a customer-managed CMK and later revokes access, historical logs become unreadable to Redwood unless the key is re-provisioned. We'll document these behaviors in the attestation.

- Delivery: we can produce monthly redacted snapshots to your S3 cross-account bucket. We'll include a hashed index file so auditors can verify integrity.

If you want, I'll draft the 1–2 paragraph deletion workflow and include it in the attestation. Otherwise, propose a 30-min call Friday morning to finalize artifacts.
