Subject: Benchmark results & unit-economics — Fintech POC (raw + summary)

Hi all,

Attached are the raw results and a short summary from the Jun 9 runs. TL;DR: the configuration that best matches Olivia's acceptance criteria is a 4x A100-eq cluster using the quantized model variant. Key numbers below (all medians unless otherwise noted):

Summary metrics:
- Average tokens / sec (per GPU): 4150 tokens/sec
- Sustained QPS (end-to-end, aggregate): 220 QPS sustained over 20 minutes (meets 200 QPS target)
- TTFT (time to first token): p50 = 115 ms, p95 = 238 ms, p99 = 420 ms
- Generation latency p50 = 75 ms / request, p95 = 190 ms
- Concurrency: passes 100 concurrent sessions with degraded p95 latency but sustained throughput (see CSV)
- GPU utilization: p95 ~ 88% during peak windows

Unit economics (sandbox traffic profile, daily 2.4M tokens):
- Hosted (pay-as-you-go) estimate: $1.24 per 1M tokens ⇒ ~$2,976 / month for the sandbox
- Redwood Dedicated estimate (reserved 4x cluster): effective unit cost ≈ $0.31 per 1M tokens after amortized reservation and utilization assumptions ⇒ ~$744 / month (not including enterprise support add-ons)
- Break-even point estimated at ~3.8M tokens/month between hosted and Dedicated assumptions given our pricing model and the planned utilization.

Attachments: benchmark_results_2025-06-09.csv (raw timeseries), rdw-cost-model-2025-06.xlsx (cost model workbook).

Notes / caveats:
- We used a quantized model variant for the cost numbers; unquantized runs show ~18–25% slower tokens/sec and ~30% higher cost per token.
- TTFT p95 is slightly above the 200ms target in some runs (238ms). Mitigations: enable prefix KV caching for warm sessions and a low-latency fallback model for strict p95-sensitive paths. We can run a focused TTFT run if you want us to prioritize that.
