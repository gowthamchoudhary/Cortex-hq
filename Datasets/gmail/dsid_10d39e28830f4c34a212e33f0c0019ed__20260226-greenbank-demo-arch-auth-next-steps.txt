Marcus — thanks for the context. High-level recommendation and a thin slice plan below (can expand into a one-pager / diagram if useful):

1) Auth ownership: GreenBank-managed service accounts + OIDC token exchange (recommended)
   - Pros: full control of key material, integrates with your KMS and rotation policies, easier compliance story.
   - Cons: requires minor infra work to enable token exchange; Redwood will provide short-term bridge if needed.

2) Concrete MVP pattern:
   - Server-to-server: GreenBank issues service account JWTs. Redwood accepts JWTs with audience=redwood-ingest and validates via your JWKS endpoint. We create a short-lived internal session token (10m) for routing and caching.
   - Client apps (internal dashboards): Use per-app API keys with read-only scope. Keys are stored in your secrets manager and rotated quarterly via an automated job that calls Redwood's key-rotation API.
   - Tooling/writes: Protected behind a separate, dedicated route that requires an explicit elevated token and step-up MFA from your side for ticket-create flows.

3) SDK notes (short):
   - Server: exchange service account JWT -> call /v1/session with Authorization: Bearer <JWT>, receive short-lived token; attach token to subsequent calls.
   - Browser: never expose service-account tokens; use backend-for-frontend to mint per-session tokens.

4) Routing & model selection:
   - Implement header-based routing: X-Redwood-Intent: read|write. Read requests hit cheaper quantized model variant; write/critical flows route to Dedicated pool with stricter logging.
   - Embeddings/reranker: compute embeddings in batch jobs where possible; reranker calls can be pinned to Dedicated for latency consistency.

5) Audit & evidence:
   - Redwood can provide token-level traces and a weekly export to your S3 for the SOC 2 evidence bundle. Monica will own the export configuration.

6) Effort & timeline (6-week MVP):
   - Architecture + notes: 2 engineer-days (Lauren)
   - Integration work (token exchange + SDK snippets): 6–8 engineer-days (split between GreenBank and Redwood)
   - Testing + audit wiring: 3 engineer-days
   - Total: ~11–13 engineer-days.
