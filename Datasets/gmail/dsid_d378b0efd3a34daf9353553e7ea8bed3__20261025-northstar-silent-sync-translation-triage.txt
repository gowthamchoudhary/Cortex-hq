Thanks — dug into the pcap and trace. Key findings:

- Evidence of forward progress (data segments) from on-prem -> server, but delayed ACKs from server side for 15–40s windows. During those windows the sender retransmits and backs off.
- TCP MSS looks consistent, but I see fragmentation on a handful of packets at the partner edge: packets with DF set that exceed 1420 bytes are being dropped and retransmitted.
- There are intermittent duplicated SYN packets seen from the server when the flow first establishes, followed by SYN retries with identical 4-tuple — suggests hairpin/NAT path oscillation where two SNAT points are momentarily in play.
- Traceroute shows two plausible return paths: primary via the new private tunnel, secondary via a public egress peer. TTLs and AS paths indicate split-horizon behavior at the partner handoff.

Hypothesis: the on-prem -> VPC path is experiencing MTU/fragmentation drops at the edge (DF set packets being dropped), combined with a split-horizon routing asymmetry that momentarily causes packets to egress a different SNAT egress causing the server to see unexpected source ports and trigger delayed ACKs / retransmits. Conntrack on the gateway may be re-allocating ephemeral ports on handoff, creating a short window where packets are accepted but ACKs mismatched.

Immediate recommended mitigations (low-risk):
1) Apply PMTU clamp on the VPC handoff to 1400 on the gateway (temporary) to avoid DF-drop-induced stalls.
2) Ensure security group allows the ephemeral port range 32768-60999 between the VPC and on-prem exit path (we saw a few ACKs blocked by an SG that only allowed 49152-65535).
3) Add a short-lived static route on the gateway to prefer the private tunnel for the on-prem subnet to avoid flip-flopping during peak.
4) Enable and monitor conntrack sticky mapping for the affected SNAT pool to prevent port rebinds during path change.

I’ll prepare a step-by-step runbook for these steps. If we still see stalls after PMTU clamp, we should capture a simultaneous packet trace on both handoff points for correlation.
