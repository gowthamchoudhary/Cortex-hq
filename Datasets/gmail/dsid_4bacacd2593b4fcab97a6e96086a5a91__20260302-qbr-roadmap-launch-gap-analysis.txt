Summary (technical):
1) Dedicated v2 routing (Target GA: 2026-04-15)
   - Remaining work: finish multi-tenant isolation checks, finalize autoscaler tuning, run two 72h performance soak tests in us-west2.
   - Top risks:
     * Risk A (medium): Autoscaler edge-case causing transient request drops under burst. Mitigation: circuit-breaker and staged rollout (10% -> 50% -> 100% over 2 weeks); additional telemetry dashboard already instrumented.
     * Risk B (low): Minor kernel selection regressions on older Ampere SKUs. Mitigation: fallback kernel and pre-deploy smoke tests.

2) Hosted streaming improvements (Target GA: 2026-03-28)
   - Remaining work: finalize backpressure handling with streaming buffer, implement partial-token streaming for JS SDK, e2e latency regression tests.
   - Top risks:
     * Risk A (high): Backpressure bugs could manifest as out-of-order fragments for long tokens. Mitigation: conservative buffer thresholds and beta with limited SDK set; rollout gating by client version.
     * Risk B (medium): Increased memory pressure with long-context sessions. Mitigation: KV cache TTL tuning and memory-aware batching policies.

3) KV-cache warming / auto-population (Target GA: 2026-04-05)
   - Remaining work: implement cross-route prefix caching, integrate with request-level hints, add eviction metrics.
   - Top risks:
     * Risk A (medium): Cache poisoning for shared prefixes under misconfigured clients. Mitigation: strict namespace isolation + validation on hints.
     * Risk B (medium): Warm-up traffic causing bursty billing for Dedicated customers. Mitigation: throttled warm-up and cost-tracking alerts; opt-in.
