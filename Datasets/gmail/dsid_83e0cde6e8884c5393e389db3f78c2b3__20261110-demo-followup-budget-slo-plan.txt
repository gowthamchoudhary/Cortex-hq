  - With KV prefix caching (client-side keying + 20% hit rate assumed): effective tokens reduced ~20%, so effective $/1M tokens ~ $168 equivalent
  - Latency: p95 ~180–260ms depending on model variant and region. Streaming reduces perceived latency for end-users.

  - Bigger batch sizes (batch windows up to 60–120ms) can reduce compute cost by ~15–25% but add tail latency. If you accept p95 <= 350ms, expect another ~10–15% cost reduction vs streaming baseline.

- Quantized model option (int8/4-bit)
  - Can drop model inference cost 25–35% with modest quality delta; recommended to run A/B on key prompts during the pilot.

- Dedicated (1-month reserved)
  - Typical recommendation: 1–2 GPU pods reserved for a pilot (~$Xk commit) — for Atlas volumes that maps to a 1-month reserved commit of roughly $20k–$35k depending on the GPU class.
  - Unit-cost improvement vs Hosted: ~20–40% depending on sustained utilization.
