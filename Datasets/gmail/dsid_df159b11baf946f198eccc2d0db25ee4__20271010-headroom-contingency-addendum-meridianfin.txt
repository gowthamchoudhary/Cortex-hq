Hannah / Lauren — internal notes / suggested language for the addendum. Kept concise so legal can pick up: 

- Definitions: 
  - "Reserved Pool": 16 dedicated GPUs allocated to MeridianFin; billed on reservation schedule.
  - "Headroom Pool": a shared, vendor-managed pool used to service short-duration bursts for reserved customers.

- Throughput guarantee (example clause): "Redwood guarantees baseline per-GPU throughput of 120 tokens/second for the model family specified in Exhibit A, measured across production workloads with sequence-length distribution provided by customer during onboarding. Guaranteed throughput is subject to verification runs; failed verification permits mutually agreed remedial steps."

- Burst / Headroom invocation: 
  - Customer may request headroom via API flag or support ticket; invocation allows up to 3x baseline throughput for up to 10 continuous minutes per instance without additional reservation fees; longer use will consume billable burst tokens at agreed rate.
  - Preemption: Headroom is best-effort. In scarcity, Redwood may preempt active headroom sessions starting with non-high-priority routes; preemption order and notification window (30s) described in runbook.

- Queueing and tail SLOs: 
  - 95th percentile tail latency guarantee for synchronous endpoints: X ms (fill in in exhibit after verification).
  - 99th percentile: best-effort with crediting schedule.

- Credits / Remedies: 
  - If verified throughput < guaranteed for an entire calendar month (after verification step), customer receives pro-rated service credits equal to Y% of monthly reservation fees. (Terms to be calibrated with finance.)

- Monitoring / Reporting: 
  - Redwood will expose per-route telemetry (95/99 latency, sustained tokens/s) and provide a monthly SLA report; ad-hoc reports available for verified incidents.

- Operational trial: Recommend a 30-day verification window post-signing where both sides run representative load tests to validate the throughput numbers; if the test shows material variance, route to remediation plan rather than automatic credits until fixed.

Notes: keep the language modular so we can escalate headroom purchase to a larger reserved buffer if MeridianFin wants more than 10% contingency. Happy to drop this into the draft PDF.
