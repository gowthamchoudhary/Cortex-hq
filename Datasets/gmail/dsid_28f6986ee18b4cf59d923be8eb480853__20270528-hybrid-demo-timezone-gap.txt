Hi Alex — thanks for the note and the agenda attachment. Looping in Jordan (solutions architect) and Camila (product engineer) to cover API/hand-on lab details.

Short answer: we generally recommend splitting into two focused blocks for global teams. A single long block tends to fatigue participants and makes the hands-on lab harder to manage across timezones. Our usual approach that balances depth and attendance is:

- Block A (45-60m): Console walkthrough + RBAC, org setup, demo tenant tour (concise admin path + troubleshooting tips)
- Block B (60-75m): API enablement + live token exchange, SDK examples, and a 20-30m hands-on lab against the sandbox
- Optional +30m: Architecture & performance tuning (run by Jordan) or an open Q&A for mixed attendees

Suggested logistics:
- Run Block A for a broad cross-section (Americas-friendly time) and Block B scheduled ~3-6 hours later to catch EMEA/APAC participants, or run on consecutive days if preferred.
- We'll provision short-lived sandbox keys for each attendee and share an instructions stub ahead of time.
