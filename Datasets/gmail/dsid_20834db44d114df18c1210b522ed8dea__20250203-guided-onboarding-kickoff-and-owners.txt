A few notes for kickoff:
- Strong preference for server-side event emission as the source of truth (gateway/control plane), with SDK/client hints only where needed for UX (e.g., “configured retries”).
- We should define a strict event schema v1 early and constrain cardinality (tenant_id, user_id, api_key_id, route/model optional but controlled).
- TTFS/TTFP: we’ll need to validate against both gateway logs and billing usage tables, given dashboard lag can skew perceived “success.”

If we agree on the schema this week, we can stand up a baseline funnel + freshness checks quickly.
