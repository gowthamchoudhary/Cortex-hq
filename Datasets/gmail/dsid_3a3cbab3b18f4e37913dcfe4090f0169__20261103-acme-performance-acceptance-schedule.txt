Quick KV cache notes from the diagnostics team:

- We captured KV traces (attached) for a representative multi-turn flow. The big wins are when prefix reuse > 60% across a session; smaller agent sessions show limited cache benefit.
- For 32k windows the cache warm-up cost (first request after model load) is significant — recommend a lightweight pre-warm that replays the user's last 1-2 messages prior to full run. That reduces TTFT for the warmed path by ~180-220ms in our tests.
- Memory tuning: raising the per-worker KV slab by 8% reduced cache eviction thrash for the 64k experiments, which improved 95th pct by ~15%.
