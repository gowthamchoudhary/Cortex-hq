Q: Where do requests execute?
A: Hosted requests execute on Redwood-managed runtime clusters. Primary regions:
  - US: us-west-2 (primary), us-east-1 (failover/scale).
  - EU: europe-west1 (for EU-dedicated pools / region pinning).

Evidence: processing-regions-20260605.csv (attached).

Q: Which subprocessors may handle request data?
A: Inventory (high level):
  - AWS (EC2/EKS) — compute (US regions).
  - GCP (Compute Engine / GKE) — EU compute when region pinning requested.
  - Fastly — streaming/edge; ephemeral buffering only.
  - Datadog — telemetry and aggregated traces (no raw prompt storage in default config).
  - S3-compatible storage (Redwood-managed buckets) — model artifacts and optional customer logs (only if enabled).
Evidence: subprocessor-roster-20260605.pdf (attached).

Q: What are TTLs for runtime caches and how is deletion enforced?
A: Defaults:
  - KV/prefix caches: 30–120 seconds TTL depending on workload.
  - Response streaming buffers: <60 seconds.
  - Optional long-lived caches: customer opt-in; TTL configurable (days) and visible in console.
Enforcement: eviction occurs at TTL expiry + background compaction jobs. For erasure requests (e.g., account deletion) we run an asynchronous erasure pipeline that:
  1) Revokes access tokens and rotates encryption keys for any stored caches or persistent logs.
  2) Runs targeted deletion jobs against object stores and index tables.
  3) Writes an audit event and returns a completion status. Typical completion for transient caches: minutes; for persisted logs/objects: 24–72 hours depending on object size and replication.
Evidence: erasure-workflow-diagram.png (attached); we can provide a CSV of deletion job run-ids if you want audit artifacts.

Q: Cross-border transfers?
A: Behavior: hosted requests may traverse regions for routing and efficiency. Controls:
  - Region pinning: customers can request to have execution restricted to EU-only or US-only clusters.
  - Contractual safeguards: our DPA includes SCCs for EU customers; we can also add additional clauses on data residency on negotiated contracts.
Evidence: DPA excerpt available on request; see processing-regions-20260605.csv for region mapping.
