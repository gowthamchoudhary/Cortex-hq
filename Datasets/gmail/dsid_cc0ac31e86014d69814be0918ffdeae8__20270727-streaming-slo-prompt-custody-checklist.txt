Looping in a proposed measurement approach so we can iterate quickly when Nova sends the final prompt bundle and traffic profile. Draft attached: measurement_matrix_v1.xlsx (columns: metric, measurement method, sample size, pins).

Key reproducibility rules I'm proposing (please review):
- Pin model artifact: exact model SHA and tokenizer version. No floating latest tags.
- Canonical prompt normalization: strip metadata fields, canonicalize whitespace, and apply a deterministic RNG seed for any sampling steps.
- Deterministic tokenization: vendor tokenizer version recorded and checksumed in artifacts.
- KV-cache warmups: include warmup sequence and record pre-warm vs warmed metrics separately.
- Throughput shape: two shapes (sustained and spike). Sustained: 12 concurrent streams, each generating an average of 3 turns/minute with 30 tokens/turn. Spike: 32 concurrent streams for 60s with bursts up to 10 turns/minute.
- Measurement windows: run 10 repeats of 5-minute windows for sustained shape and 6 repeats of 2-minute burst windows; compute P50/P95/P99 across runs.

Suggested initial thresholds we should use for test gating (pilot):
- Token emission latency: P50 <= 120ms, P95 <= 300ms (as discussed).
- First-token latency P95 <= 350ms.
- End-to-end throughput: sustain at least 1,000 tokens/sec for the sustained shape.
