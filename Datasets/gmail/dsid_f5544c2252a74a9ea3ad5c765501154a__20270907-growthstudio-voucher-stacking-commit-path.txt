Elena — thanks for the note and for sending the usage matrix. Really excited about partnering on the cohort. Quick responses below and I set a 30-min slot for 10:00am PT tomorrow.

- Voucher stacking: yes — we can stack the one-time cohort voucher on top of sandbox credits for this cohort as a short-term exception. We typically avoid stacking promo credits by default, but given cohort programs are a strategic motion we can make it work under a few guardrails (see below).

- Conversion to reserved (commit) path: we have a conversion mechanism: leftover promo value can be applied as a one-time credit toward the first month of a reserved capacity contract (not ongoing discounts). For larger conversions we can consider a committed-offset addendum that phases credits across the first three months.

Guardrails I'm proposing for ops/finance approval:
- Voucher stacking limited to cohort enrollments only (internal enrollment list required)
- Max stack per team: $7,500 promo value + sandbox baseline (we can adjust)
- Conversion credit applied only on execution of a reserved commitment within 90 days of cohort end

I've attached a simple mutual action plan (MAP) template and a sample cohort usage cap table for ops to review. If this looks good I'll coordinate with finance/legal for an approval path.
