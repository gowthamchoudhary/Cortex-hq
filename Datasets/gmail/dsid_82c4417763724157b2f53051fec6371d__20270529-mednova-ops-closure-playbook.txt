Adding a few technical guardrails from the SE side.

Hannah's plan is sensible. A couple of concrete thresholds we suggest placing in the MAP so the decision is objective:
- Latency: if p95 > 400ms for two consecutive business days under the expected token mix, trigger Dedicated pilot.
- Cost: if token cost per 1k requests on Hosted exceeds Dedicated estimated unit cost by >25% under the PoC traffic profile, flag for migration evaluation.
- KV cache correctness: if user session cache miss rate > 12% at peak, we need Dedicated with larger instance types for stable KV memory.

Operational notes:
- We'll supply a perf harness and a small synthetic workload for MedNova to run against the Hosted PoC. That gives quick visibility into p95 and token unit economics.

Estimated provisioning time: Hosted PoC (us-east) — 48–72 hours after account approvals; Dedicated pilot — 2–3 weeks to reserve and configure nodes + routing. Private/on-prem — schedule depends on network access and KMS integration, typically 8–12 weeks.
