Hi Lena — quick answers and a short checklist for the canary evals. Attaching a sample prompt set and the benchmark PDF — see attachments.

Short answers:
- Cross-encoder outputs: we can provide span-level attribution when the reranker is configured to score passages at sentence granularity. For your KB the implementation we suggest will surface both the passage id and the sentence offset for top-ranked hits (so you get per-sentence provenance).
- For the 1k labels: please include passage ids if possible (easier to map to reranker training), but raw doc ids are fine if mapping is trickier.

Canary eval checklist (high level)
- Deterministic prompt set run: baseline promptset v1 (attached) — measure grounding precision, hallucination rate, and coverage@k.
- R@k / recall: retrieval recall@1/5/10 vs. labeled answers.
- Reranker lift: delta in grounding precision and MRR when applying cross-encoder vs bi-encoder.
- Latency profile: p50/p90/p95 token latency + end-to-end answer latency (including retrieval + rerank + LLM).
- Regression gating: fail if grounding precision drops >2.5% against baseline or hallucination increases >1.5%.

Technical notes / quick starter configs:
- Retriever: HNSW (M=32, ef_search=128), vector dim=1024, normalize embeddings. Use batch size 256 for indexing.
- Reranker: distil-cross-encoder-mrpc tuned on KB slices, candidate k=10 for training.
- LLM prompts: use the attached promptset v1; include an explicit "source: [PASSAGE_ID]" token in the system instruction so the model must cite.

We’ll also include a small Jupyter notebook in the Drive folder showing how to compute grounding precision and hallucination rate from the model outputs.
