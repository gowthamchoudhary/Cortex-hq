Jonas / team — read the requirements quickly. Technical highlights and initial concerns:

- Isolation: We can support per-tenant logical isolation with dedicated namespaces and billing tags; full per-tenant GPU isolation adds cost but is feasible for flagged customers.
- On-prem: We have a private deployment package (air-gap) but it requires customer-managed HSM/KMS for key material. We'll need 8–12 weeks for an appliance POC (ops + security sign-offs).
- Billing & telemetry: We can push aggregated telemetry (latency, token counts, error rates) and per-tenant tags for Skyline to bill downstream. We must ensure no PII leaves the instance; recommend a filtering layer at Skyline edge.
- Versioning & rollouts: For white-label, we recommend a pinned-major-version policy with opt-in upgrades to avoid breaking Skyline customizations.
