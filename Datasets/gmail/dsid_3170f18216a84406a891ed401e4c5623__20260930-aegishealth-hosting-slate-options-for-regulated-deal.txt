Sizing options (pilot 3-month horizon):
Option A — Dedicated Reserved (fastest onboarding, predictable cost)
- Baseline: 12x A100-80GB in a dedicated pool (supports 50 rps sustained, 450 concurrent sessions with batching and multiplexing).
- Burst: allow burst to 18x A100 for short windows (contracted burst credits).
- Estimated committed MRR (list): USD 68k–80k depending on term/discount.
- Lead time: 2–4 weeks after PO.
- Compliance: Dedicated + VPC egress + customer-specific routing + dedicated tenant logging; logs retained per contract (we can ship logs to your S3).
- Pros/cons: quick, lowest time-to-value; less hardware control than Private.

Option B — Private (VPC / on-prem appliance)
- Baseline: 3x H100-80GB nodes (we size nodes so each provides higher per-node throughput vs A100); effective parity for 50 rps with p95 < 350ms. For headroom and spiking, we recommend 4x H100 to match burst requirements.
- One-time platform fee + HW procurement: $1.2M–1.6M capex (depending on vendor/hw choices) + annual managed support (15–20% of capex).
- Lead time: 10–14 weeks (procurement, on-site installation, security review).
- Compliance: full control over keys, audit logs retained on your storage, optional air-gapped setup.
- Pros/cons: maximum data control and slightly better unit economics at scale; long lead time and heavier ops ownership.

Operational recommendations:
- Hybrid path: start with Dedicated (quick onboarding) with a documented migration path and playbook toward Private if Aegis decides to buy hardware after pilot. The migration plan includes: (1) pinning model versions, (2) exporting KV cache priming sets, and (3) a traffic cut-over window with dual-write tracing.
- Quantization & model tradeoffs: consider an 8-bit fine-tune and an eval prompt set to validate quality delta. If quality regressions occur at 8-bit on your prompts, reserve an option for 16-bit slices for critical routes.
- Autoscaling policy: set conservative cooldowns and pre-warming for predictable spikes. Use burst credits to avoid cold starts.
