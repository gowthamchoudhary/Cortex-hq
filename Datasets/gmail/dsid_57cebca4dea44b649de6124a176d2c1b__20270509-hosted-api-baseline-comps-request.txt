Tom — thanks for the clear ask and for the forecast. Attaching our current hosted API ratecard (PDF) — the doc has baseline generation and embedding lines plus our standard committed discounts. High level (summary):

- Baseline generation: $0.016 / 1k prompt tokens + $0.032 / 1k completion tokens (example model tier)
- Baseline embeddings: $0.006 / 1k embedding units
- Committed discounts: 10% at $50k/mo committed, 18% at $200k/mo, 30% at $500k/mo (negotiable with term)
- Burst: short-term bursts allowed up to 2x baseline throughput; overage billed at committed tier rate or default list depending on contract.

For competitive context (high-level ranges we see in market):
- OpenAI: generation ~ $0.02–$0.04 /1k tokens depending on model; embeddings ~ $0.006–$0.01
- Anthropic: similar to OpenAI on generation in many cases, embeddings generally closer to $0.007–$0.012
- Together: typically positioned lower on list price for generation but with fewer enterprise guarantees; embeddings vary by model
- AWS (Bedrock-related offerings): list prices can be higher or similar depending on model and infra costs, but AWS bundles more into commit/enterprise arrangements

Those ranges are intentionally directional — exact apples-to-apples comparison depends on model family, sequence lengths, and whether KV/prompt caching applies.
