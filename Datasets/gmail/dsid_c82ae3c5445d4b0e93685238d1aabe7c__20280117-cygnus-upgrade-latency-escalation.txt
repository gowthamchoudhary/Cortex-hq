Quick technical readout from initial trace pass:
- The Q2 quant profile flips a kernel selection for long-context decoding to a new integer-matmul path. On our infra it shows periodic stalls when the KV cache crosses a 48k token threshold on this model variant.
- Those stalls explain both the p99 jump and the decode failures (the runtime aborts long-running decode attempts when latency headroom is exceeded).
- We see error signatures consistent with a miscompiled kernel on a subset of GPU micro-architectures (likely older A-series).

Immediate mitigations that are low-risk:
1) Serve a mixed routing for affected customers: route 100% of Cygnus hot-path traffic to the legacy quant profile until we patch.
2) If mixed routing isn't fast enough, perform an emergency rollback of the quant profile on the affected pool (rollback plan attached).
3) Hotfix: deploy a runtime guard that disables the new kernel selection for models with >32k token sequences while we produce a deterministic kernel fallback (estimated 6–12 hours).

I've attached a short analysis (p99-traces-analysis.txt) and marked the suspected kernel callsites. If Cygnus can confirm the GPU SKU(s) in the affected fleet, that would speed root cause.
