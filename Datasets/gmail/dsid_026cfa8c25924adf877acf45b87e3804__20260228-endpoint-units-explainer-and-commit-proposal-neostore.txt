Hi Michelle — thanks for the clear list. I pulled in Laura (pricing) and Karthik (SE) to make sure we cover both the billing model and the math for your two patterns. High level first, then a worked example.

Short answers:
- Responses (the unified chat & completions surface) is billed on total "compute tokens" = prompt (input) + model-generated (output) tokens. The unit on the rate card is per 1,000 compute tokens.
- Legacy Chat (/v1/chat) and Completions (/v1/completions) are still supported under the hosted API for a limited transition window; they map to the same billing units when using equivalent model families, but we list legacy pricing as separate line items on the rate card for clarity (you'll see a "legacy" column).
- Streaming does not change token accounting — tokens emitted by the model are billed the same whether streamed or returned in a single payload.

Hi Michelle — quick, plain-language breakdown plus worked examples attached (see Neostore_MAAP_Draft.xlsx). Key points:

1) Unit definition (hosted Responses API):
- Billing unit = per 1,000 compute tokens (prompt + completion).
- Example: a single chat turn with 40 prompt tokens and 80 completion tokens = 120 compute tokens => billed as 0.12 units (120 / 1000).

2) Legacy endpoints:
- Legacy /v1/chat and /v1/completions are shown on the rate card for customers still transitioning. Pricing is functionally the same for equivalent models; we provide a temporary legacy line item for accounting.

3) Streaming and early termination:
- Streaming responses are billed on tokens actually emitted. If a client truncates the stream early, only tokens generated are billed.

4) Long-sequence and batch summarization (2,400 tokens avg):
- For 2,400 compute tokens per request => 2.4 units per request. If you run 1,000 such jobs in a month: 2,400 units total.

5) Price examples (from the v3 rate card included):
- Base list price (Responses, per 1k compute tokens): $0.012 per 1k tokens (example model family on hosted tier).
- Using that list price: interactive chat (avg 0.12 units/turn) at 100k turns/month => 12,000 units => $144 at list price.
- Batch summarization: 1,000 jobs/month * 2.4 units = 2,400 units => $28.80 at list price.

6) Commit/discount guidance:
- Standard first-year commitment bands: 5% off for $50k+, 10% off for $100k+, 15% off for $250k+. These are illustrative — we can provide a firm quote for your $150k commitment.
- In practice, discounting also depends on model mix (some newer/large models carry different base prices) and whether you want Dedicated capacity.

7) Contracting notes:
- We can provide a 12-month committed-spend proposal with monthly caps and true-ups. For $150k ARR commitment we typically outline: guaranteed committed spend, monthly invoice cadence, and a usage reconciliation clause. I'll draft a sample with the numbers you provided and send the MAAP.
