Emily / Logan — quick technical breakdown to help procurement/legal evaluate tradeoffs. Attaching SOW_draft.pdf for scope reference. Key points: 

- Hosted (EU region):
  • Latency: ~18–35ms typical for Helix EU endpoints (estimate based on test dataset).
  • Isolation: logical tenant isolation; prefix KV caching shared across host but keyed per-customer.
  • KMS: supports customer-managed keys via cloud KMS; HSM token-based wrapping requires Dedicated/Private for full HSM passthrough.
  • Cost: lowest TCO to start; autoscaling reduces idle waste.

- Dedicated (EU reserved GPUs):
  • Latency: ~12–25ms (depending on instance type + batching).
  • Isolation: physical pool reserved to Helix; stronger guarantees for noisy-neighbor avoidance.
  • KMS/HSM: can integrate with tenant KMS; limited HSM support via partner integration (needs validation).
  • Cost: ~25–40% premium vs Hosted for committed capacity (depends on commit length).

- Private (VPC / on-prem):
  • Latency: depends on customer infra; can be best for intra-datacenter traffic.
  • Isolation: full network isolation, private control plane option, HSM integration supported (on-prem HSM or cloud HSM proxy).
  • Ops: longer lead time (2–6 weeks for infra, plus SSO/KMS work).
  • Cost: highest; also carries ops/maintenance overhead.

Recommended short-term path for Helix: commit to Dedicated in EU for initial production (SLA + predictable performance) while we scope Private/HSM for a later phase if Legal requires on-prem HSM. That lets procurement commit faster and gives Legal time to evaluate HSM integrations.
