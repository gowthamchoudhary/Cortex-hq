Quick notes from a security/ops perspective:

- KMS / Secrets: We support two models: (A) customer KMS via cross-account IAM role (preferred for cloud private endpoints) or (B) HSM-backed key material for fully air-gapped on-prem (requires secure key export workflow). I'll attach our KMS integration guide.
- Certificates: We recommend short-lived leaf certs (7-14 days) with automated rotation. For BlueArc on-prem we can install a small cert-rotation agent that talks to your internal CA over mTLS.
- Installer / air-gap: The installer tarball contains container images + checksums; for air-gap we provide a manifest and signed tarball. Laura — please confirm checksums and offline install steps in the attached preflight.
