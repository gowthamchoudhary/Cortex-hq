High level requirements:
- Time-to-first-token (TTFT) for streaming must be <= 200ms for payloads under 1k tokens for 95th percentile.
- Sustained tokens/sec during steady-state inference: ~800 tokens/sec for our throughput tests (burst up to 3k tokens/sec for short windows).
- For very large models / quantized variants, we accept longer complete-response latencies if TTFT is met; but we need clear fallback behavior and crediting policy if token-rate falls below threshold.

We attached a spreadsheet with our expectations and a few sample traces. Carol / team —

Thanks for the clear ask, Carol. I reviewed Aditya's draft and created a more prescriptive playbook that we can include in the SOW / appendix. Key changes and operational definitions below; please see the attached PDF for the full proposal.

Executive summary (proposed carve-out):
- Measurement points: TTFT measured at the edge (first byte emitted to client) at 95th percentile over rolling 7-day windows; sustained token-rate measured at the inference layer over rolling 60s windows, aggregated at 99th/95th percentiles for slowness detection.
- Thresholds (proposal):
  * TTFT streaming SLO: <= 200ms (95th) for model classes A/B; 350ms (95th) for model class C (large quantized models).
  * Sustained token-rate: >= 600 tokens/sec (95th) for production baseline; allow short bursts up to 3k tokens/sec for <= 30s without penalty.
- Fallback behavior: if token-rate < 600 tokens/sec for two consecutive 60s windows -> automatically route subsequent requests to sync endpoint variant until token-rate stabilizes for a 5-minute window.
- Credits/penalties: tiered credit schedule tied to total impacted minutes during the billing period; immediate SLA incident created in Redwood Console and exported to shared Drive.
- Monitoring/alerts: recommended Grafana alerts + a Redwood Console route-level metric dashboard with alerting to Aurelia on-call (we propose integration via PagerDuty)

Open items for Aurelia:
1) Confirm whether model-class granularity (A/B/C) is acceptable or you'd prefer per-model thresholds.
2) Confirm crediting floor (we propose 1 hour aggregate impact before credits apply for POC).
3) Approve the draft call time — Thu 27 May 09:00 PT / 12:00 ET — or propose an alternative.
