Hi Priyom / Redwood folks,

Thanks — the diagram looks good as a starting point. Quick answers below: 
- Egress: production tenants will egress via our transit CIDR through the customer-managed firewall (we prefer transit so we can centrally apply DLP rules). For the pilot we can allow direct internet via a managed NGW.
- NAT: for scale we will provide managed NAT (stateful) but we can hand off to customer-managed appliances during cutover if you require it.
- MTU: default 1500 on our fabric; jumbo frames are not enabled end-to-end today.
