Agree we should keep this pragmatic. My proposed rules (quick):

1) Public (all clouds): Core entry tier (Pay-as-you-go, small token bundle) + community models.
2) Partner-only / gated: Dedicated reserved SKUs and enterprise bundles (monthly commit) — enabled when customer commit >= $15k ARR or monthly consumption >= 1M tokens.
3) Region defaults:
   - APAC: prefer GCP for cost/latency in select markets (SG, JP) unless customer requests AWS.
   - EU: prefer Azure for gov/compliance-heavy accounts in DACH region; otherwise AWS for broader footprint.
   - US: no default — present both and let co-sell routing pick based on account tier.
4) Packaging: Marketplaces prefer single-line SKUs; map our bundles into single SKUs with metadata for add-ons.

Operational asks: if we gate a SKU, we must add a one-click request flow in the listing (link to reseller onboarding) and a HubSpot tag so Sales can claim co-sell. I added inline comments in the offer-catalog-v1.xlsx.
