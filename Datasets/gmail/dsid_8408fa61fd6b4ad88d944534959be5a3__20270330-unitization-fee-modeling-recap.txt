Attaching short write-up in the template and pasting the quick sensitivity summary below. I kept the math conservative on model size / seq length to avoid overpromising latency-based batching gains.

Summary assumptions (conservative / expected / aggressive):
- Active users seeing feature (pilot months): 25k / 150k / 450k (of 650k total)
- Prompts per active user per month: 0.5 / 1.0 / 2.0
- Avg tokens per prompt (round trip): 280 / 420 / 650
- Token consumption per month (calc):
  - Conservative: 25k * 0.5 * 280 = 3.5M tokens
  - Expected: 150k * 1.0 * 420 = 63M tokens
  - Aggressive: 450k * 2.0 * 650 = 585M tokens

Cost & pricing bands (examples):
- Redwood incremental inference cost (estimated): $95 / 1M tokens (conservative) to $130 / 1M tokens (expected) — varies by quantization and batching.
- Proposed list price bands: $650 / 1M (pilot light SLA) | $1,000 / 1M (standard) | $1,350 / 1M (premium SLA / embeddings included).

Implied monthly bill (list price) & margin vs expected cost:
- Conservative (3.5M tokens): list bill at $650/1M = $2,275; gross margin ~  (1 - (95*3.5/2.275)) ~ very high (we show exact numbers in the sheet).
- Expected (63M tokens): at $1,000/1M = $63,000; our cost at $115/1M = $7,245; gross margin ~ 88% before infra overhead adjustments.
- Aggressive (585M tokens): at $1,000/1M = $585,000; cost at $115/1M = $67,275; margin ~ 88% but consider reserved/dedicated discounts and capacity commits which reduce unit cost materially.

$/feature framing (list price per 10k activations):
- Chat baseline (per 10k activations): uses avg 420 tokens/interaction -> 4.2M tokens -> list price at $1,000/1M = $4.2k per 10k activations.
- Summarization uplift (adds ~0.6x tokens): ~6.72M tokens per 10k -> $6.7k.
- Search-rewrite (lighter): ~2.1M tokens per 10k -> $2.1k.

CAC payback (example):
- If ARPU = $12/mo and CAC = $120 => payback = 10 months. 
- If ARPU = $12/mo and CAC = $40 => payback ~ 3.3 months.
- If ARPU = $18/mo and CAC = $240 => payback ~ 13.3 months.

Recommendation for Medly pilot:
1) Start pilot at mid-tier list pricing ($1,000/1M) with a capped pilot commitment of $60k/mo for the first quarter to validate retention and feature uplift.
2) Offer a per-feature bundle price for summarization (e.g., $3.0k per 10k activations) during the pilot so procurement can map to specific product KPIs.
3) Re-evaluate after pilot month 2 with actual tokens/user to calibrate quantization & reserved capacity discounts — we can then present a commit path to drop unit cost by 20–30%.
