I pulled the node and autoscaler logs for VG-DC1. Quick summary:
- Around 08:42 we saw a sudden increase in queued tokens and sustained GPU memory pressure on 3 nodes (NVIDIA A40 pool).
- Autoscaler fired scale-up requests at 08:45 but nodes only became available after ~7–9 minutes due to cold-start provisioning + image pull backlog.
- There are visible eviction events (OOM-driven container restarts) starting at 08:46 which correlate with 5xx surfaces.
- Retry amplification: multiple clients (including Vanguard) hit retry policy that amplified queueing; we observed many identical requests re-entering the queue which prolonged recovery.

I've started a temporary mitigation: bumped the fallback to a smaller quantized model on the affected route and enabled a soft rate-limit for the customer’s API key to reduce retry traffic. That reduced error rate by ~60% by 09:02.

Logs: node events + autoscaler excerpt attached. Next steps: fast follow on improving warm spare capacity and adjusting cold-start limit knobs.
