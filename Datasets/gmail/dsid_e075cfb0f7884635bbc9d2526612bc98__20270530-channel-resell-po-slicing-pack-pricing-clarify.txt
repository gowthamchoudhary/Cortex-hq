Maya — thanks for the clear list. Short answers up front, longer below so you can forward to AP/Finance: 

- Multiple POs per account: yes, we can accept multiple POs and map them to one billing account. We can emit a consolidated monthly statement that lists each PO as a separate line.
- Net terms: our standard for enterprise is net45; we can consider net60 on a case-by-case basis for channel/resell. If net60 is required, procurement should expect a small price adjustment.
- SKU bundling: we support both patterns — either separate line items per bundle (preferred for PO reconciliation) or a single aggregated line. For faster reconciliation we recommend separate line items that include the bundle code in the PO line description.
- Docs: the PO template is perfect. We need remittance details, billing contact, and the PO number. If they can add a reference to the Redwood account ID in the PO (acct: AX-2027-0893) that helps our ERP matching.
