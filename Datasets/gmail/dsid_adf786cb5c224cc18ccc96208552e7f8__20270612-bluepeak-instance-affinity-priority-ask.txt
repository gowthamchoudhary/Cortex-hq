Marissa / all —

Short answer: shim is feasible but has defined constraints. High-level notes:

- Implementation: add tenant-affinity tag at the routing layer + warm-cache TTL pinning. This requires changes across request router, cache manager, and autoscaler hooks. Estimated dev: 10 engineer-weeks total. If we staff 2 engineers full-time and prioritize, we can hit a pilot-capable subset in ~3 weeks (dev + integration smoke tests) as Marissa suggested.

- Isolation caveat: the shim reduces cold-start latency for the pinned tenant, but storage-level isolation is still shared. For customers requiring cryptographic separation and zero co-residency, Dedicated remains the only honest answer.

- Risk: affinity TTL leakage and incorrect eviction could cause QoS for other tenants; we’ll need the ops team to add monitoring and a rollback plan (1–2 days ops ramp).

- Cost & SLA: we should propose a higher unit price for pinned residency in shared infra OR push them to a Dedicated quoting path. If they opt for dedicated capacity we can guarantee tenancy and tighter SLA but with a commercial uplift.
