Lily — thanks for the quick turnaround and the diagram. We reviewed the file and I’ve attached our preliminary responses (PDF) to the questionnaire — called out the hosting options and where BAA applies. A few clarifications inline:

- Access to logs: for Dedicated & Private, raw request logs that could contain PHI are restricted to customer-facing ops via role-based access. Engineering access requires approval and is audited. For Private (on-prem) the customer controls log storage.
- Retention: default request-log retention is 30 days on Dedicated; we can shorten to 7 days with config and an add-on for longer immutable retention. Token cache retention is per-deployment and we provide KV cache controls; for PHI we recommend disabling persistent token caching unless explicitly required.
- Hosted API: we treat Hosted as ineligible for PHI unless the customer opts into a bespoke enterprise routing contract that pins requests to a dedicated, isolated fleet in a single region and signs the BAA + addendums. That is a longer legal path and not our default.
