High-level pilot objectives
- Validate latency and throughput at target scale for the text-classification pipeline we discussed.

Proposed gating criteria (pass/fail for acceptance):

- Cost: Target inference cost <= $0.0008 per token (end-to-end, including batching overhead).
- Quality: Task F1 >= 88% on the labeled evaluation set; human preference in blind A/B >= 70% (vs current baseline).
- Reliability: Error rate (5xx or timeouts) < 0.5% during soak.

- Week 3 (quality readout + acceptance): Run labeled evaluation and blind human preference test; review results with BlueScale and decide accept/reject. Owner: Marcus + Lauren (CS).
