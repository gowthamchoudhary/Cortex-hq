Hi Emily — thanks for the note. Below is a concise breakdown; attaching a redacted summary and a coverage matrix for your procurement team. Full report can be shared under our standard mutual NDA.

High-level coverage (default Redwood annual pen test):
- Hosted API (Redwood-managed runtime): IN-SCOPE — all runtime clusters we operate for hosted customers are included.
- Redwood Dedicated (reserved capacity): IN-SCOPE only when Redwood provisions and manages the node images, OS, and the inference stack. We run the same internal pen test process across those pools.
- Dedicated (customer-managed images / SSH access): OUT-OF-SCOPE by default. If a customer brings their own image or has admin access, that environment falls under customer responsibility. We can coordinate a scoped, third-party engagement on a case-by-case basis.
- Private / VPC deployments and On‑Prem: OUT-OF-SCOPE by default — network and host control are customer responsibility. We provide a pen-test runbook and can assist with vendor engagements (costed).
