Acceptance appendix — condensed (pilot 6 weeks)
1) Performance (must pass at checkpoint):
   - Latency: p95 inference latency <= 350ms on production-like payloads (95% of requests)
   - Stability: no >1.5x increase in median latency under 10k qps burst relative to baseline
2) Functional accuracy / fidelity:
   - Intent match / exact intent recall >= 92% on labelled sample of 1k queries
   - Hallucination incidents <= 2% (defined as factually incorrect medical advice on review sample)
3) Cost target (operational guardrails):
   - Average token cost per request within 18% of agreed pilot estimate
   - Canary throughput supports SLA at peak 2x expected baseline
4) Security & compliance (exit gate requirements):
   - SOC2 Type II evidence provided or attestation (we can supply SOC2 report redacted for customer)
   - Data retention policy validated (90-day retention with documented purge path)
   - KMS integration test passes (customer KMS key usage verified in staging)
5) Acceptance tests (what Lumen runs / Redwood supports):
   - Integration smoke: 100 end-to-end sample queries (pass rate >=95%)
   - Regression suite: run customer's labelled 1k sample set (metrics as above)
   - Load test: 2-hour sustained load at 1.5x expected peak with latency SLOs met
   - A/B drift check: small shadowing / A/B comparing current production responses vs Redwood outputs on 5k queries
   - Failover & rollback: automated fallback to model variant tested with observed latency under target within 5 minutes of simulated failover
6) Exit gates (decision logic at week 3 / week 6):
   - Week 3 (midpoint) — proceed if: performance and integration smoke pass; no critical security blockers; customer satisfaction score >= 3/5 on integration checklist
   - Week 6 (final) — proceed to production if: all metric thresholds above met, or if a single non-critical failure has documented mitigation + agreement on timeline to fix
