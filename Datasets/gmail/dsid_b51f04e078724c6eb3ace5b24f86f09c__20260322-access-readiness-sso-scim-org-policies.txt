1) SSO/SAML (Okta)
   - SP metadata attached: upload to Okta as a Service Provider.

   - NameID format: emailAddress.
   - Recommended signing algorithm: RSA-SHA256.

2) SCIM provisioning
   - Endpoint: we configure a SCIM v2.0 endpoint per tenant.
   - Minimal attributes: userName (email), externalId (employeeNumber), active, displayName, groups (by externalId).
   - Custom attributes allowed: costCenter, location — provide mapping in the attached sheet.

3) IP allowlists
   - We will provide a region-specific static egress set for webhook callbacks and admin console access (see checklist).
   - For your staging -> prod cutover, you can register the staging set first and add prod ranges 24 hours before cutover.

4) Service accounts & org policies
   - We recommend a machine/service account per integration; keys are short-lived (90 days) with automated rotation.
   - For audit purposes, we log service account usage per token and tie to the tenant id.

5) Audit & compliance
   - We capture admin actions (SSO config, SCIM toggles, allowlist changes) in the tenant audit log and provide export for SOC2 review.
