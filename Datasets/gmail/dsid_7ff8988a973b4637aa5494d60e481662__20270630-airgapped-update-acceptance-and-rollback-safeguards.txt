Adding the ops checklist and network constraints we require on the site:

On-site prerequisites (network / operator):
- No outbound NAT/egress to the Internet from the appliance management plane during verification.
- Switch port isolated (VLAN tagged but no route to corporate network).
- Operator console (serial or local KVM) available; we cannot rely on remote access.
- Time sync: set to a local NTP server reachable from the appliance (we provide recommended stratum).

Verification commands (examples we will run with your operator present):
- sha256sum image.tar.gz && echo "<expected-hash>"
- cosign verify-blob --key-identity <redwood-root> --signature signed-image-bundle-20270628.tar.sig image.tar.gz
- tar -tvf image.tar.gz to confirm layout (images/, manifests/, keys/)

Rollback safeguards:
- Prior-stable image included as prior-stable-image.tar.gz. Operators should NOT delete the prior bundle until 24 hours after post-window sign-off.

Alice / team —

A few cryptographic and manifest notes from the artifact side:

Signing and verification:
- We sign bundles with our hardware KMS using cosign (detached signature). The bundle also contains per-image SHA256 checksums and a manifest (redwood-offline-manifest-v1.yaml) with file-level hashes and roll-forward metadata.
- We will provide two verification options:
  1) Offline verification binary: a small statically linked verifier (redwood-verify v0.9) we include on the media. It performs checksum + signature verification without network.
  2) cosign verification with provided public key fingerprint if you want to run it on your operators' laptop (offline, using local copy of cosign).

Chain-of-custody / media handling:
- Media will be encrypted with LUKS and courier will provide tamper-evident seal ID. Manifest includes the seal ID and courier receipt format (printed).
- On handover, operator signs printed manifest (operator name, time, seal ID). We require a scanned image sent to our secure mailbox within 4 hours of handoff (if network policy allows) OR the courier logs with signed receipt if scans not permitted.

Emergency rollback flag:
- The manifest includes a boolean flag emergency_rollback_allowed. Set to false by default; we will only enable true via signed approval from Saturn security contact.

I'll attach a short README with the exact cosign commands and the public key fingerprint in the manifest.
