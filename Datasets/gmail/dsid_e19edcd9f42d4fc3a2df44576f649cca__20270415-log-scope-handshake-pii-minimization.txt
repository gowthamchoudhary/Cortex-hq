Martin, Sofia — adding the technical details so Greenline can assess feasibility and mapping to your evidence requests.

Technical export playbook (high level):
- Supported formats: line-delimited JSON (JSONL) with newline-separated events; Apache Parquet (partitioned by date) for large snapshots; CSV for sampled slices.
- Manifest & integrity: each export includes manifest.jsonl with per-file SHA256 + overall manifest SHA256. Enterprise exports optionally signed with our HSM key and including an HMAC (customer-shared secret).
- Time fidelity & TZ: timestamps are stored in RFC3339 UTC; exports preserve original timestamps plus an epoch field for deterministic sorting. We include timezone-normalized chunks if requested.
- Sharding & size: large time windows are sharded by hour/date to keep file sizes < 20GB.
- Redaction: fields marked in schema as redactable can be redacted server-side at export time. We support deterministic hashing (sha256 saltable) so you can still map identities across exports if needed. Note this hash is irreversible unless you provide the salt.
- Chain of custody: we include an export events log (separate ledger) that records who requested the export, IP of retrieval, and delivery handshake (S3 presigned URL issuance or SFTP session id). Audit trail is included in the bundle.
- Sampling caveats: when sampling is requested for performance, we mark the bundle with the sampling ratio and seed so it’s reproducible.
