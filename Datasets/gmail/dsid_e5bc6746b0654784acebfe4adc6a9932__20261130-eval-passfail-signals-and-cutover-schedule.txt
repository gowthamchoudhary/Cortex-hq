Olivia —

Appreciate the MAP — good baseline. I pulled together a concise acceptance-test matrix and a suggested cutover cadence below. I attached a slightly edited MAP and our standard SLA/Smoke template (SLA_SR_template.pdf).

Core acceptance tests (what we run, and pass thresholds):
- Functional correctness (intent/slot match): evaluation dataset of 3,000 representative queries; pass if top-intent accuracy >= 95% and slot extraction F1 >= 92%
- Response quality regression: side-by-side A/B comparison vs your incumbent on 500 sentinel prompts; no more than 5% relative drop in task completion rate
- Latency: p95 end-to-end < 300ms for 1–512 token responses during 10qps sustained; degrade gracefully at 50qps
- Cost / throughput stress: sustain 100 qps for 10 minutes with error rate < 1% (for Dedicated mode we’ll simulate expected production traffic)
- Cache effectiveness: KV/prefix cache hit >= 30% on proxy run (to justify unit-cost estimates)
- Security/compliance: SOC2 evidence provided, audit logs enabled, data retention policy confirmed (default 30 days; options available)
- Failover policy verified: automatic fallback to fallback-model X for OOM/latency incidents; fallback must not exceed 10% of requests during test window

Exit gates (order of gates we recommend):
1) Legal/Procurement: signed SOW or PO for pilot resources (minimal commit)
2) Security: gap-less confirmation of SOC2 + evidence folder + retention settings configured
3) Functional: pass functional correctness and response-quality checks on canonical datasets
4) Reliability: latency & stress thresholds met in Dedicated/Hosted equivalent environment
5) Production-readiness: smoke tests in direct-API mode with two production-like partners

Cutover schedule (suggested, compressed 3-week eval):
- Week 0 (prep): SOW signed, accounts provisioned, test data sanitized
- Week 1 (proxy): proxy traffic run (3k sample queries), collect metrics, iterate prompts
- Week 2 (stress + smoke): 100 qps stress test, p95 latency measurement, A/B quality checks (500 prompts)
- Week 3 (decision & cutover): go/no-go meeting, staged ramp to 10% production, validate SLA metrics for 48 hours, full cutover 1 week after greenlight

Acceptance test harness & ownership:
- Redwood provides an eval harness (scripts + datasets) and a runbook; HealthSync provides production-like test data and two product SMEs for quality reviews.
