Hi Sam — thanks, and great questions. High-level answers below and I've attached a control map and architecture diagram for your intake team.

Summary (short):
- Scope: Our Hosted API and Dedicated offerings both map to the same SOC 2 control framework; differences are in evidence ownership. Hosted: Redwood provides attestable service controls and artifacts; Dedicated: we supply the same controls but customers get an isolated pool and can own some operational controls (e.g., network ACLs). Private (VPC/on-prem): customers manage the control plane for some responsibilities.
- KMS/Encryption: Hosted supports Redwood-managed KMS with customer-supplied envelope keys via our KMS integrations (we can integrate your cloud KMS). Dedicated and Private support customer-managed keys and HSM-backed workflows; Private can be configured for BYOK in most cases.
- Audit logs: We emit JSON-line audit logs, exportable to your S3/GCS, and retain 12 months by default for enterprise accounts. Immutable retention for longer windows can be configured with write-once storage in partnership with your cloud bucket policy.
- Data residency: We maintain region-specific endpoints (US/EU/APAC). Private deployments can be placed in customer VPCs within specific cloud regions.
