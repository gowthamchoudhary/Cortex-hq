Thanks — I put together a short plan and model recommendations. Summary below (full notes in the Drive link).

Model recommendations (fast shortlist):
- gpt-small-quant (16-bit quantized rev A) — best cost/latency for short structured outputs (expected median latency 45–70ms on p4d-like nodes).
- llama-2-13b-q4f — stronger accuracy on entity extraction, will need 1.5x cost but fewer regressions on merchant IDs.
- fallback: open-instruct-7b — lower cost fallback for burst capacity; expect looser schema strictness without stricter decoding constraints.

JSON-schema compliance plan:
1) Synchronous schema validation: after model finishes, runtime runs a JSON schema validator and returns a compliance flag (schema_ok: true/false) plus an errors array when false. This is the default path.
2) Streaming/schema fail-fast: for streaming outputs we will emit partial chunks and insert an inline compliance_annotation event when a chunk breaks declared schema (example event: {"type":"schema_violation","offset":347,"reason":"missing required field 'merchant_id'"}).
3) Deterministic fallback: when schema_ok:false and errors include missing required fields, the runtime can: 1) retry with a tighter decoding temperature + sampling constraints; 2) call a helper function (reranker) to repair; or 3) fall back to a smaller deterministic parser. We'll instrument all three and capture metrics.

Retry/backoff specifics:
- Default retry policy: up to 2 retries with exponential backoff (200ms -> 600ms) for schema failure or tool-call timeouts.
- For network or infra nacks we treat as transient and use immediate retry with jitter.
- We will record per-retry success and increased latency to produce an SLO impact table.

Observability artifacts we'll provide in the eval: per-request schema_ok, errors, retry_count, model_variant, decode_time_ms, total_latency_ms, kv_cache_hit (true/false). We'll also include a dashboard link and a CSV export for offline analysis.

Benchmarks: I ran a quick pass on the prompt set you gave — attached is a short PDF with model-level precision/recall and schema compliance. Highlights: gpt-small-quant hits schema_ok 92% out of box; llama-2-13b-q4f hits 97% but with higher p50 latency. Full results: https://benchmarks.redwood.ai/acme-summary-202609 (internal link).
