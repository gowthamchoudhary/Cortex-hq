Account & rack network punchlist (high level):

1) Account foundation (before fiber install)
- Shared VPC CIDR: recommend 10.20.0.0/16 per-tenant baseline; reserve /24s per availability zone for host subnets.
- Control plane egress: please allow outbound to these IP ranges for Redwood control plane and telemetry: 34.120.45.0/24, 52.201.10.0/24.
- DNS: create an internal FQDN zone for <env>.redwood-orchid.internal and an A record per host.
- Service accounts: confirm a dedicated service account for provisioning with least privilege; we will provide a JSON for permissions.

2) Rack & L2-L3 (on-site)
- Rack mapping: provide U positions and management VLAN (we recommend VLAN 4094 for out-of-band mgmt).
- VLANs: data VLAN (VLAN 200), management (VLAN 4094), storage (VLAN 210). Tagging required on trunk ports.
- IP plan: allocate /28 per server for management; static IPs for BMC, console, and primary NIC.
- MTU: 9000 for the data path (confirm switches support jumbo frames).

3) Connectivity & NAT/Firewall guidance
- Border NAT: prefer 1:1 NAT for public control-plane egress IPs; avoid hairpin NAT for health checks.
- Firewall rules: allow outbound TCP 443 to control plane CIDRs; inbound only from Redwood maintenance IPs when agreed.

4) TLS & KMS
- KMS endpoints: if using customer KMS, provide endpoint and required IP allowlist; for HSM, schedule key injection window with our security team.
- Certificates: bring cert chain for internal load balancer; we require RSA-2048 or better.

5) Smoke validation (day 0)
- Test: token-auth against control plane, ping/latency checks to selected model-serving gateway, quick inference smoke-run (sample payload).
- Telemetry: confirm telemetry egress and sampling tolerances; list of metrics expected.
