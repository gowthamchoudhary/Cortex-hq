Thanks for the thread and the draft artifacts. I reviewed the matrix and crosswalk; high level notes below that you can share with Zenwell legal/compliance.

1) How Redwood implements the exclusion:
- Object tagging: transcripts created with the "ephemeral: true" metadata are routed to short-lived buckets with 0–30 day TTLs depending on workload.
- Indexed copies (for search/routing) are stored as hashed pointers; raw transcript text is not retained beyond TTL unless explicitly promoted.

2) Required compensating controls for an exception from 7-year archival (recommended):
- Retain audit trail for creation, promotion, and deletion events (immutable append-only logs, retained 7 yrs).
- Periodic attestation: quarterly snapshot and signed attestation from Zenwell that no promoted transcripts exist beyond agreed criteria.
- Forensics export capability: we commit to a 72-hour secure export window if Zenwell needs a snapshot for an investigation (subject to discovery process).
- Access control: role separation enforced (SRE vs. platform admin vs. customer data steward) and MFA for admin actions.

3) Evidence we will provide:
- SOC 2 test report snippets that reference change management and deletion procedures (excerpted).
- CAIQ control mapping (the PDF included) with pointers to configuration screenshots and log samples.
