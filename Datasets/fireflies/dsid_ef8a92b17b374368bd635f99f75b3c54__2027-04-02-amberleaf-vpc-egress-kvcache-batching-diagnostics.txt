Amberleaf VPC Egress, DNS & KV-Cache Batching Diagnostics

Deep diagnostic session focusing on intermittent P95 latency spikes during peak hours for Amberleaf's private VPC deployment. Main suspects: VPC egress NAT capacity, DNS resolver timeouts, and suboptimal KV cache sharding causing tail latency. Discussed temporary mitigations, long-term architectural changes (PrivateLink multihoming, dedicated NAT pools, resolver caching, KV cache affinity), and a plan for an on-prem load test + synthetic traffic run. Agreed next steps and owners.
